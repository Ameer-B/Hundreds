# Hundreds — Hover-to-Grow Game

Hundreds is a minimal, skill-based game where you hover over circles to make them grow.  
Each circle increases in size while your cursor is on it, and the goal is simple:

**Get all circles to a total value of 100 without letting any circles touch.**

This repository contains my custom-coded version of the game, built from scratch.

---

## Gameplay
- Hover over a circle to make it grow.
- Circles pause when you're not touching them.
- If circles collide while growing, the game resets.
- Reach a combined total of **100** to win.

---

## Features
- Smooth circle growth animation  
- Collision detection  
- Real-time total counter  
- Clean, minimal UI  
- Fully custom logic (no external game engine)

---

## How to Play
1. Clone the repository  
2. Run the project in your browser or game environment  
3. Hover over circles and try to reach 100
